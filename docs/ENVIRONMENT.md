# 环境能力与实际支持范围

[返回首页](../README.md)

这是带可选辅助脚本的 Agent Skill，不是自带模型、运行时或独立医学引擎。各宿主自行提供模型、权限、检索、文件与执行器。

| 能力 | 所需条件 / 当前范围 | 已知限制 |
|---|---|---|
| 阅读与写作 | 实际可读文本；宿主完成语义任务 | 读取摘要不能冒称精读全文；现有结果解释不等于复算 |
| 文献 | 已有全文 / 权威记录，或可用检索工具 | 无网络不能称最新检索；受限全文保留缺口 |
| Python 辅助 | Python 3.11+；requirements 按任务列出 | 依赖未捆绑，不自动安装，未测试所有版本组合 |
| XLSX / CRF | openpyxl；方案、字典、映射充分 | 返表不能猜字段；XLSX 不能由文本核验替代 |
| 统计 | 已有 Rscript / jsonlite；宿主核方法前提 | 明确范围内描述、比较、线性 / 二分类关联、简单留出预测；复杂纵向、聚类、生存、因果、多重插补等通用执行未验证 |
| 图形 | NumPy >= 2.0、Matplotlib >= 3.9；真底数 | 缺库返回环境阻断；不按显著性选择图；位图无底数不能精确重绘 |
| Word | python-docx、Pillow、覆盖实际文字的字体 | 当前 Mac 有限排版证据；复杂稿件、Word 跨平台显示仍需核验 |
| PDF / 页图 | 已有 LibreOffice / Poppler | renderer 需要 runtime-root 下 dependencies/bin/override 布局；其他布局须适配，不能保证找到任意工具就可运行 |
| 字体 | 现有字体或 YE1_FONT_PATH 指向现有字体 | 不捆绑字体。TTF/OTF 字形检查；TTC 等备用检测需 Matplotlib / FreeType |

本机解压、CLI 启动、有限缺库检查与代表实画，不等于 Codex / WorkBuddy / 豆包 / Claude Code 等真实平台注册、安装或科学任务验收。Windows / Linux 和真正无执行器宿主未验证。

缺能力时保留输入、已完成文本、真实表和冻结底数，标待续任务。不能称已重算、已绘图、已核全文或已生成未实际产出的文件。医生不需要自行安装 Python 的前提是其宿主本来就有可用执行器；不能把这一点写成无执行器也能跑完整流程。
