# 数据使用选择与真实边界

[返回首页](../README.md)

当前源码为privacy-002。38入口及总入口内嵌37任务继承同一个项目的A/B选择。A：原始/逐行资料留在获准本地，只回传经检查且精确授权的汇总/稿件/图。B：指定文件版本或裁剪范围到指定平台、模型，用于指定目的。缺失、冲突、扩大范围或换目的不能静默继承。

**没有任何真实宿主在本项目中被验证为受控隔离宿主。** 普通任意读文件/shell的Agent不能由提示词、env或host.json保证严格执行。未知宿主须暂停研究数据步骤；不要为过检查伪填host=true。没有Python时也不能转云上传原件。云端已经接收的附件不能因后来选A撤回。

本版旧prepare/package与export共用事务锁、授权字节快照和原子发布，修复检查后重读/收紧竞态。并发收紧返回CHOICE_BUSY表示未成功，必须重试。暂不支持到期授权；客户提出限时条件时暂停，不能删条件继续。相同choice的UNCHANGED分支不会保存新evidence条件，不能把它说成限时授权已生效。

本地export只是生成ZIP，没有真实发送器/发送账本；READY不是已上传。实际隔离、可信审阅、接收方及用途约束均需受控宿主实现。JSON汇总校验不是通用PII/OCR检测；稿件、图片、元数据仍需可信本地审阅，小单元/重识别规则由机构确定。

原件与日志保存在获准项目中，对外材料逐成员、版本、目的核查；不自动上传、调用额外模型或投稿。供应商接收、保留/训练策略须按实际宿主/服务核对。本预览只用于公开/合成材料；不是隐私或安全认证。

详细规则见[总入口数据选择](../skills/ye1-research-workflow/references/data-use-choice.md)，各独立入口同样自带此规则及控制脚本。
