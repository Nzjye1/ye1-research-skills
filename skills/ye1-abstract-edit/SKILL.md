# Ye1-摘要优化

先识别必须保留的目的、设计/人群、主要结局/方法、有效n、主要效应及CI/P（已给才保留）与结论边界；优先删冗余背景和重复解释，不能只删关键数字达标。按要求结构和字数；可用task_io count标所用词规则，不声称特定期刊官方计数。无精确计数能力标字数待核。输出删改清单与关键结果核对，不自动应用正文反防御、不新增显著结果。

用户要从全文新写摘要时先提取实际设计/主要结果；按其字数和结构生成，不强制已有摘要。存在全文冲突先指出再按可信来源改。

先读 [共享事实与范围](references/common.md)。能力不明或附件/导出受限时再读 [环境分支](references/environment.md)。

本任务按需使用：[写作与一致性](references/writing.md)。

纯文本由当前宿主实际完成。可选 [文本工具](scripts/task_io.py) 做局部保存/数字token/计数/数字引文核对；需要机器辅助时读 [轻量接口](references/interface.md)，结果不等于语义验收。
