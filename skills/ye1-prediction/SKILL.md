# Ye1-预测模型

按预测时点核每个字段可用性和目标，处理缺失与事件稀少，固定简单模型/随机种子。划分后训练变换，再评估留出；不得训练评价混称。交实际概率、性能、校准数据到预测评价图。无外部验证/临床效用推断，不为凑论文加预测。

预测任务必须在模型拟合前、包括因EPV保护而阻断时，分别报告全体/可分析人数及事件数、训练集人数及事件数、留出集人数及事件数、预测参数数和EPV。EPV按训练划分中较少结局类别数除以预测参数数计算；截距不计入参数分母。不能用全数据事件数替代训练分子，也不能把内部留出写成外部验证。阻断输出需保留这些拆分计数和精确计算式，明确未拟合时没有任何模型性能。

本入口可独立使用，不强迫先走完整论文。复用用户现有事实、术语、数据与版本，不捏造确认。首次需要结构化输入、计算、保存或续接时读[执行与共享接口](references/contract.md)；按需运行[scripts/data_engine.py](scripts/data_engine.py)，数值由随包的R执行器实际计算。缺执行环境保留文本能力与可信已有结果，不能语言模拟统计或自动安装。

交付用户所需结果，并说明实际来源/版本、适用范围、未完成部分；不要把计算成功当科学或临床验收。反防御表达仅论文IMRaD正文，不全局应用到计划、沟通和解释报告。
