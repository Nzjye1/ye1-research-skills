# Ye1-完整论文

沿用已有研究确认、方案/实际分析与可行性记录，识别当前可写范围。宿主按本研究问题、方法、实际结果和证据组织提纲并实际撰写完整审阅稿，可从外部稿件补全；不是拼通用模板。先冻结共同事实与论据再写中/英文，引用按具体主张覆盖。缺方法/结果只在相应位置留可读待核，不伪造伦理、纳排、机构、随访或实验；阴性和小样本不机械阻断全文。新分析交分析模块并取得必要研究确认。交完整可读稿、来源/结果位置和待核清单；排版/确认打包由相应模块续接。内部物化格式由宿主自然产生并校验，客户无需手工 JSON。

先读 [共享事实与范围](references/common.md)。能力不明或附件/导出受限时再读 [环境分支](references/environment.md)。

本任务按需使用：[写作与一致性](references/writing.md)；[检索/阅读/证据](references/literature.md)。

纯文本由当前宿主实际完成。可选 [文本工具](scripts/task_io.py) 做局部保存/数字token/计数/数字引文核对；需要机器辅助时读 [轻量接口](references/interface.md)，结果不等于语义验收。

## v0.4.2 确认来源

医生正常说“确认这个方案/版本”即可。宿主保存实际原话、所在消息/外部原记录定位、日期与目标版本，不让医生写JSON。记录分direct_user（可直接引用的用户消息/记录）、simulated（模拟）、unknown（宿主摘要/自填姓名日期/来源未明）。缺省为unknown，不能冒称真实批准或出真实确认交付包。直接记录也只证明当前文件中有该原话，不能证明真人身份或文件没有被宿主造写；本地文件/哈希不提供密码学身份认证。模拟仅测试，来源不明保留待确认。旧v041裸字段记录仍可阅读，真实交付前补核来源并获当前版本确认；正文/图表/方法/支持文件变化使旧确认失效。软件ZIP不需要稿件确认，不自动投稿/发布。

首次加载、依赖缺失、升级或移除时见[独立使用与环境](references/portable-use.md)。
