

# 保留的完整论文能力（v04，沿用v0.3范围）

先用中文医生话术讲“现在能做什么、缺什么、现实能补什么、补不到就不能说什么”。优先解决临床问题，不让医生先理解工具合同。读取既有确认，已答不重问；没有且补不到随访，只确认并记录一次，不等于无事件。

本包固定自动引擎覆盖**每人首次住院的有限描述、CRP首末配对、氧疗比例与实际图**；自动全文仅为明确合成数据的受限模板演示。其他研究的全文由当前宿主根据真实事实和证据撰写，再用通用物化接口导出；**通用临床全文自动生成、复杂模型、多专科泛化及真人体验未验收**。不能用固定稿冒充通用写作能力。

## v0.3 客户审阅与初稿确认

先读 [审阅及引用接口](v03-review.md)。默认自动生成客户审阅稿，图表放首次相关正文引用附近；中英文独立语言路由，中文实际图内标题／图例／坐标／单位必须核验，英文文献原题名保留。通用初稿样式不等于具体期刊规范。

方案科学确认不等于稿件版本确认。用户／客户明确确认对应审阅版本之后才用 `review_delivery.py` 生成已确认初稿包；结果、稿件或引用证据变化会使旧确认失效。软件安装zip可以正常打包。禁止伪造确认；测试合成记录仅用于测试。当前演示待用户审阅，未取得初稿确认。

完整宿主稿用冻结参考ledger和正文稳定 `[[R1]]` ID；核身份、实际内容位置、对应主张、相反证据、局限及源哈希，再自动生成首次引用编号。不要仅填写reference_review布尔式声明；不要设置凑数门槛、把metadata核对当全文支持或把编号检查当科学审稿。

## 新表、新背景入口

医生上传任意新表或提出新研究背景时，执行 [宿主全流程](host-workflow.md)：先用独立于指标的 `profile.py`盘点所有表，再由当前宿主实际完成方法沟通、可重复分析、真实文献核证与完整双语写作。不要求新表具有CRP示例列，也不把背景固定为住院描述。超出固定引擎的统计必须基于问题实现或说明能力缺口。通用results键及物化接口支持不同背景，但宿主全流程尚未做多问题科学验收。

## 正式分析与全文前的发表评估（必须消费）

新表入口顺序：profile结构盘点 → 必要语义核对 → 有界公开近邻检索 → 发表可行性报告 → 一次集中必要确认与补证 → 冻结方案 → 分析 → 结果核对/文献缺口复查 → 全文。先读 [v0.2接口](v02-integration.md)。不要把后置参考文献步骤当作前置近邻比较。

报告向医生明示临床价值、已有研究做到了什么、本项目能增加什么、主张与证据覆盖及体量、关键缺口和具体建议；七维分别表达，不加权、不全AND。小样本、阴性、合理重复、普通局限、期刊未选和仅摘要级阅读不自动STOP。具体不可补且影响主张的证据才标CRITICAL；普通不足标ADVISORY，逐项指定QC/描述探索/确认性效应/投稿活动。创新包括有理由的重复验证，不要求新指标。期刊与文章类型未定保持OPEN，不保证SCI/中文核心录用。

当前CLI `inspect/analyze/run` 必须附 `--gate GATE --case CASE --evidence-root ROOT --question QUESTION`；`compose`另附 `--source ORIGINAL`。先用 `publication_gate.py CASE --root ROOT --out NEW`生成回执与报告。病例JSON按示例填入宿主有依据的判断、证据/哈希、问题与源指纹，不自动搜索或独立科学审查。原表/问题/病例/证据变化须重评；不得伪造确认。只有未解决CRITICAL阻断受影响活动。确认性效应还需真实数据和既有方案确认；固定CRP引擎只做描述，不能用确认性权限声称实现复杂效应分析。

合成演示即使STOP当前投稿也可按描述权限运行。`compose --synthetic-demo`要求稿输入`scientific_confirmation: simulated`，持续注明合成；真实稿需`confirmed`并对应已有医生事实。本包不授予投稿资格。80例营养演示的前置5项摘要级近邻及建议见 [比较](publication/近邻比较.md)，只作流程与描述演示，不推进临床投稿，不加预测/生存凑篇幅。

## 图形 v0.2 实际接口

`graphics.py`提供分布/比较、散点、森林、流程、ROC、PR、校准、DCA八类；`route`核显式前提，不能替代科学确认。预测需固定分数/明确结局时点与验证角色；DCA另需临床行动和合理阈值。删失/生存当前拒绝。用局部`theme(language)`、现有字体fallback与字形检查、`export`输出PNG300dpi/SVG/PDF及数据审计，不安装或复制字体。

CRP CLI实际调用新绘图worker，中英文各生成新图并物化对应稿；重复坐标面积编码次数，不移动坐标。校验保留原始点逐点重算、x/y一致、重复人数守恒、字形/边界/刻度及输出哈希，替代旧SVG circle标签计数。物化图宽13cm，保持设计字号；目标期刊终稿另核。主Python缺Matplotlib时明确设置`DOCTOR_PAPER_GRAPHICS_PYTHON`为已有绘图Python。依赖见requirements，不自动安装。

## 实际入口

脚本全部相对本Skill目录。先按 [环境分支](environment.md) 由宿主判断实际能力。已有Python后使用 `scripts/safe_run.py pipeline doctor --request all --runtime-root EXISTING_RUNTIME`；无Python先走文本分支。实际脚本要求Python3.11+；不自动安装。运行与恢复说明见 [使用说明](usage.md)，配置字段见 [输入及写作接口](interface.md)。

- 仅问“能不能做”：检查原表结构，宿主说明可行范围；可用 `pipeline.py inspect INPUT --config CONFIG --out NEW`，不出图或推断结果。
- “帮我分析”：先确认人/住院层级、时间、单位、结局及重要处理规则；保存来源、日期和确认内容。常规代码不逐项索批。匹配受限范围时执行 `pipeline.py analyze INPUT --config CONFIG --out NEW`，默认交两张真实图和结果；超范围时给出限制及具体需扩展的方法，不强套本模式。
- 合成完整演示：用 `pipeline.py run INPUT --config CONFIG --references references/evidence.json --out NEW`，仅接受标记合成、模拟科学确认及无随访的演示配置。从同一结果自动生成中文与英文全文、表图、DOCX；`verify NEW`核确定性数字/物化/图形合同。
- 真实稿／其他问题：宿主先检索公开文献，逐项核身份与内容支持，保存题名、作者、年、DOI/PMID、查询/来源日期、主张位置和证据位置。元数据核实不能替代主张支持。宿主撰写摘要、引言、方法、结果、Discussion、局限、结论与参考文献，全部研究数字绑定结果字段；使用 `compose.py RESULTS DRAFT_JSON --out NEW`。此命令仅物化宿主稿，不自动写作或联网核证。v0.3新增冻结参考证据和双语首次出现编号；当前接口验证已登记占位符，不能保证遗漏的数字与语义也正确。

## 论文正文措辞润色（仅正文）

依据用户最新确认，仅对论文IMRaD正文应用，重点为引言与讨论；不自动扩到摘要，不应用医生对话、可行性反馈、数据分析、审核报告或投稿信。A/D轻测只是评估证据，不意味着启用这些场景。

正文润色先说具体事实与结果；必要限定与对应证据相连。同一风险说明清楚一次，避免反复自我贬低、泛免责声明和无信息量的“仅供参考”。润色不能改数值、不利结果、因果等级或实质局限；摘要与独立图注仍须具备必要范围。此处为自有轻量规则，借鉴父任务对MIT开源 anti-defensive-writing 的有限对照结果；没有整包执行，未见明确增益，来源边界见PROVENANCE。

## 科学与交付要求

不追显著性，不为阳性结果换方法。关键定义、研究单位、结局、方案改变需医生科学确认；实际更正不自动重定义。区分关联、预测与因果；复测子集不能代表全队列改善。记录日数不是康复或生存时间。未知伦理、机构、作者、资金和纳排不编造；合成稿正文必须显式标记演示，不能包装成真实研究。

图表与双语用同一结果、同一有效分母和单位。先核表/图点/方向计数，再写结果、摘要与Discussion；不要只忠实传播旧错误。固定参考证据只支持报告方法，不支持CRP疗效或预后。宿主完整稿须另核所需临床文献，不把两条方法参考当完整疾病检索。

更正时保留原表、旧产物和答复记录，用新目录。固定演示可 `run ... --previous OLD --out NEW`；列数据差异、受影响数字/段落/图表和双语文件，重建当前DOCX/PDF。真实稿在结果更新后必须重新填绑定数值、复核Discussion及所有格式，不只替换Results；定义变化暂停对应路线并科学确认。不能说当前 `analyze` 已自动生成完整更正链。

DOCX保留可编辑表格与文本；图PNG嵌入，同时交SVG。使用现有运行环境的**bundled** LibreOffice/Poppler显式渲染：`render.py DOCX --runtime-root RUNTIME --out NEW`；不要回退用户安装的桌面LibreOffice。逐页查看PNG，核中文缺字、分页、表格和图例；未看不能标视觉通过。没有现成渲染工具就交DOCX并标PDF未测，不自动安装。

给医生简短首页与文件入口，后台保留结果、数值主张、来源证据、代码和版本。A模式逐行资料仅留受控本地处理区；B仅按精确指定范围回传，均执行项目数据使用选择。新依赖安装、额外模型/预算须另核授权；数据上传复用项目已确认范围，扩大须重确认；不得擅自公开发布、推送或改权限。本版本只是可演示的本地首版，正式发布条件仍待决定。
