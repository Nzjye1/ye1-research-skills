# Ye1-审阅排版

排版不冒充科学内容审核。内部schema/路径由宿主建立；复用通用中文样式与正文图表接口。本独立包使用 materialize.py；完整引用核证和旧compose接口在总入口，不能假称本包自动核全文。Word 必须用本包所带的共享物化器；它选择现有字体并逐 run 指定 East Asian 字体，六列及以上宽表使用独立横向页面。中文Caption在选中Arial Unicode MS且检测到现有macOS Heiti SC Medium时切换为Heiti SC并保留粗体；否则关闭Caption粗体，不安装字体。排版前检测当前正文全部字形，渲染时使用任务级字体配置。不要用硬编码未经当前运行宿主验证的字体名创建替代 Word。

读取[任务规则](references/ye1-review.md)中对应部分，按用户眼前请求处理，不要求先走完整论文流程或让医生操作命令。使用[共享事实与版本](references/shared-state.md)，按[实际环境](references/environment.md)交付可做部分；需要计算/绘图/导出时实际执行，缺能力不能假称完成。

本技能目录自包含所需规则和脚本，不依赖兄弟目录。使用现有环境，不自动安装、外发患者资料、调用额外模型或发布。品牌显示名称为Ye1-审阅排版；小写slug用于宿主兼容标识。

## v0.4.2 确认来源

医生正常说“确认这个方案/版本”即可。宿主保存实际原话、所在消息/外部原记录定位、日期与目标版本，不让医生写JSON。记录分direct_user（可直接引用的用户消息/记录）、simulated（模拟）、unknown（宿主摘要/自填姓名日期/来源未明）。缺省为unknown，不能冒称真实批准或出真实确认交付包。直接记录也只证明当前文件中有该原话，不能证明真人身份或文件没有被宿主造写；本地文件/哈希不提供密码学身份认证。模拟仅测试，来源不明保留待确认。旧v041裸字段记录仍可阅读，真实交付前补核来源并获当前版本确认；正文/图表/方法/支持文件变化使旧确认失效。软件ZIP不需要稿件确认，不自动投稿/发布。
