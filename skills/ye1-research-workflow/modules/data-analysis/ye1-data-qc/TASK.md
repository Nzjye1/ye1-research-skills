# Ye1-数据质控

运行qc，按实际研究定义补查跨行/多表关系及不可能时序，区分数据问题与科学适用性。报告问题位置、影响/严重程度和明确下一步。原表不改，不能把重复就诊自动去重为患者；修正须交清洗规则。

本入口可独立使用，不强迫先走完整论文。复用用户现有事实、术语、数据与版本，不捏造确认。首次需要结构化输入、计算、保存或续接时读[执行与共享接口](references/contract.md)；按需运行[scripts/data_engine.py](scripts/data_engine.py)，数值由随包的R执行器实际计算。缺执行环境保留文本能力与可信已有结果，不能语言模拟统计或自动安装。

交付用户所需结果，并说明实际来源/版本、适用范围、未完成部分；不要把计算成功当科学或临床验收。反防御表达仅论文IMRaD正文，不全局应用到计划、沟通和解释报告。
