# Ye1-分析更新

读取用户选定基线和已答定义，分清普通更正与研究定义/方法变更。analyze --previous保存旧件、复用未受影响项、产生state-patch与下游影响；重大定义变化须真实版本确认。普通更正使旧结果依赖与旧稿件确认失效，局部更新不强迫全文重写。未登记下游需宿主补核。

本入口可独立使用，不强迫先走完整论文。复用用户现有事实、术语、数据与版本，不捏造确认。首次需要结构化输入、计算、保存或续接时读[执行与共享接口](references/contract.md)；按需运行[scripts/data_engine.py](scripts/data_engine.py)，数值由随包的R执行器实际计算。缺执行环境保留文本能力与可信已有结果，不能语言模拟统计或自动安装。

交付用户所需结果，并说明实际来源/版本、适用范围、未完成部分；不要把计算成功当科学或临床验收。反防御表达仅论文IMRaD正文，不全局应用到计划、沟通和解释报告。

## v0.4.2 更正下游核查

先盘点实际消费者：主/敏感性结果、表格/图底数与各语言图、中英正文/摘要/图注、所选Word/PDF、进度及版本确认。所有受影响项待核，旧件留存；未受影响项可复用，但不能仅替换正文主P而漏敏感性。按实际变化重算/重画/改稿/渲染，在新目录交版本。用revision_audit.py核当前analysis哈希、宿主显式选定的每个角色与成果哈希和关键数字锚点；清单由宿主维护，不让医生填。遗漏角色、旧analysis或改件均不能标下游完成；未登记消费者仍需人工盘点，脚本不证明语义完整。旧确认不移植到新版。
