# 共用事实、范围与续接

沿用 v04 shared-state/text-environment，自有增量日期 2026-10-13。

用户可直接给一句话、单段、已有章节、外部稿件或已有分析表，不必先走总流程，也不必手工拼 JSON。读取已有答复，只询问真正影响当前交付的缺项；先交可以完成的部分。连续任务共用用户成果目录中的事实/术语/证据/版本记录，单段请求不强制建项目。

保留原件，明确所选版本、目标段落、语言和输出用途。CONFIRMED 必须有用户确认或来源；ASSUMPTION 与 OPEN 不冒充已定。记录数字、单位、分母、时点、参照、缺失、否定、关联/因果、不利结果及来源位置。润色和翻译不得顺手修正疑似事实；报告疑点。范围外保持原文，只有用户扩大范围才改其他部分。

交付先给所需文本/判断，附最短够用的来源位置、阅读范围、修改说明和待核项。不把文稿审阅状态写成作者认可或投稿就绪；没有用户对该稿件版本的确认，不生成已确认稿件包。

事实、源文、证据、数字、主张或方法变更：保留旧版，列受影响段/图表/摘要/双语/引用/格式件，相关核证和稿件确认失效；仅语言变化不复算。数据变化交分析模块更新结果后再改稿，科学定义/方法改变需必要研究确认。源哈希未变也不能证明新措辞仍受支持。

默认在当前授权环境处理私人稿件/数据。检索使用去身份化的公共概念；不把患者行、未发表全文、机构敏感信息或原始数据发给外部搜索、翻译站或模型。工具存在不等于取得外发授权。已有授权连接可用于其授权范围；不得绕过访问或付费限制。

自动校验只查结构、来源指纹、已登记事实、数字 token 或位置。语义与科学性由宿主实际核对；不把程序 PASS 称医学结论正确。反防御写作只在论文 IMRaD 正文轻量使用：先说具体事实，必要限定紧随相应主张，去掉重复空泛自我否定；摘要、沟通、审核报告、投稿信和审稿回复不套用。不删局限、不抬高结论。
