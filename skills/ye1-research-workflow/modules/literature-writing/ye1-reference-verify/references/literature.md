# 检索、阅读和证据记录

按本次动作读取相关段落即可。沿用 v04 read/evidence/identity/align，与 reference-completeness-20261013 的主张覆盖交接。

## 检索
将问题拆为人群、暴露/干预、结局、设计和时点；使用中英文同义词、主题词（工具支持才用）和关键词，适度宽检后收窄。除高度知名期刊，纳入适用的专科、中文、方法文献以及可比近邻和不支持性结果。按研究问题选择来源，不承诺检索全量，不用 CNS/影响因子作为纳入标准。所需引用数由背景、方法、比较、解释和局限中的具体主张覆盖决定，不凑数。

记录日期/时区、实际来源或数据库、工具、完整查询/过滤、检索范围、看到的结果数（不是虚构数据库总量）、候选稳定 ID、URL、纳排理由、去重依据、访问失败和停止范围。只提供检索式时标 PLANNED；实际检索为 EXECUTED；离线材料筛选为 PROVIDED_MATERIALS，不伪造联网记录。近邻/反证未找到写在已检范围内未找到，不能断言不存在。系统综述另需事先方案和专门流程，不把本技能有限检索叫系统评价。

## 阅读与定位
每源分别标 METADATA / ABSTRACT / EXCERPT / FULL_TEXT_RELEVANT_SECTIONS / MAIN_FULL_TEXT，补充材料独立记实际已读部分。全文部分章节不冒称全文全表已核。记录原文件/URL、取用日期、实际位置（页码仅实际页码；无页则小标题+段首/表行），必要短引文和解释；材料缺失就保留缺口。作者讨论推测与实证结果分列。

## 身份与内容分账
身份核真给 MATCH / MISMATCH / UNVERIFIED，逐字段列 DOI、题名、作者、年份、期刊/版本与权威记录差异、来源与日期。规范化 DOI URL 前缀/大小写；无 DOI 可以有可靠题录。更正/撤稿、预印本/正式版和在线/卷期年份差异实际查到才记，不自动当不同文章。无法访问不证明文献不存在。旧快照仅说明在该日期的记录匹配，不能称新核真。

论据单独给 supported / supported_with_scope / conflicting / unsupported / unverified / local_result_only。逐个核人群、设计、构念、时点、方向、因果、数值及限定。摘要级仅支持实际摘要陈述；正文方法/表格/亚组需要实际对应内容。反证、不一致、重要局限保留，不能因支持结论而选择性删负面结果。主张拆小后给可成立措辞；原句不受支持时不能仅换引文继续原断言。

自有研究结果绑定该项目的真实结果来源；不能找一篇外部论文给本项目数字背书。某源真实不等于支持主张，支持一条也不覆盖整段所有事实。

## 引用与更新
稳定 source_id 与显示编号分开，记录原ID/别名、标准DOI/PMID、版本关系；只有确定同一来源才合并，疑似同题/冲突元数据列待核。文内/文后、图表/摘要和双语同一主张对应同一来源集合。数字引文从选定主语言或共同主张顺序统一编号；不同语序可保留非递增出现但不得变成不同文章。作者年份等风格人工保留对应，不强套数字脚本。

未用条目可留资料库，成稿参考表只列实际引用；缺条目或身份歧义先报告，再在副本修正，不静默删证据。引用改动重核相应主张、编号、双语与所有格式件；来源/主张变化撤销旧核证。脚本 receipt 不能单独恢复稿件确认。
