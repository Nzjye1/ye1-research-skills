# Ye1-引用整理

明确所选全文/节选范围和风格，提取文内ID与文后条目，查漏条目、未引用、重复标号/身份及首次顺序。数字方括号可用task_io align（含范围/多个ID）；其他风格宿主逐项映射，不强套数字regex。元数据缺失不补造，重复疑似DOI仅提出待核合并。自动重编号前先建立旧ID→稳定文献→新号，更新对应正文与列表副本；有缺条目/歧义时先报告，不强行删未用条目。编号一致不代表文献存在或主张支持。

双语共同主张复用同一稳定来源，选定主语言首现顺序统一编号；语序不同不应使同号指不同文章。证据或段落改动重核影响链。

先读 [共享事实与范围](references/common.md)。能力不明或附件/导出受限时再读 [环境分支](references/environment.md)。

本任务按需使用：[检索/阅读/证据](references/literature.md)。

纯文本由当前宿主实际完成。可选 [文本工具](scripts/task_io.py) 做局部保存/数字token/计数/数字引文核对；需要机器辅助时读 [轻量接口](references/interface.md)，结果不等于语义验收。
