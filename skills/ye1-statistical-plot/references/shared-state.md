# 共享事实与局部版本（Ye1 v0.4.1）

完整研究优先恢复项目中的ye1-project.json、进度.md和已有确认；专项可复用等价事实记录。按需建立任务记录，不要求医生填表。单次短请求可以直接交文本；连续调用时复用已确认定义。优先读取用户已有项目记录；确有多次调用时在用户成果目录（不是Skill安装目录）保存 doctor-paper-state.json 或等价可读文本，字段只记录已知内容：active_versions、facts（CONFIRMED/ASSUMPTION/OPEN及来源日期）、terminology、numbers（值/单位/分母/来源位置）、references（稳定ID/identity/content分开）、pending。各入口共用该记录，修改后保存上一版；有机器哈希才写哈希，不能人工伪造。

记录已读范围（全文/节选/预览）、来源文件及版本、用户指定范围、语言、事实状态、术语对照、数字/单位/分母/时点/参照、文献稳定ID和身份状态、实际证据位置、已交文本、待核项及下一步。确认事实附原话/日期；没有依据保持OPEN。没有执行或写入工具则交可复制交接记录，不宣称生成文件/哈希。

身份(metadata)与正文支持(content)分别记录；定位原文引用短句并标页/节/段，别把示意材料当真实论文。数字保真包含负号、CI上下限、P值、有效n、量纲和参照组；计数不等于统计正确。论述保留关联/因果、阴性/不确定、配对子集/总队列界限。

重复调用读取用户实际选定的上一版，另存新版本，限定到请求段/句；无执行时人工对照标出其余部分未改。只有语言变化不重算、不重检全部文献；涉及主张或文献变动核受影响内容，数字更正来自可信结果而非猜测。事实错误列为疑点，不借润色偷改。完整流程仍需既有科学确认和发表活动闸门；局部文本任务不把全流程闸门当不必要前置。

有执行器可按需用 scripts/task_io.py 保存精确字符范围、保留原件、检查数字token、计数或核数字引用；这不能替代宿主语义审阅。输入图片只有可见内容，未读PDF不报页码定位成功。

反防御表达仅论文IMRaD正文，重点引言/讨论：说明具体事实、将必要限制放对应主张旁，避免重复空泛自我否定。摘要、医生沟通、解释报告、投稿材料不自动应用。任何润色不删科学局限或提高证据强度。
