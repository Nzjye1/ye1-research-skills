# 按任务能力降级

从 v04 environment/text-environment 抽取。先看实际能否读取文本/完整附件、联网、执行、写文件、解析 PDF/DOCX、渲染，分别记 AVAILABLE/UNAVAILABLE/UNKNOWN；工具名或扩展名不代表已成功读取。

文本任务由当前宿主完成，不以 Python、模型 API、总入口或原始数据为前置。纯文本环境交可复制成果与可读交接；无文件工具不说已保存，无机器哈希能力不造哈希。没有检索工具则已有材料模式，记录材料日期和范围，不声称最新/全面。公开网页、已经连接且获授权的检索工具任选实际可用者，不预设某个数据库或安装。

PDF/DOCX 解析只在实际工具可用时执行。只有预览、摘要、OCR 或部分页时按实际范围说明；表格读取有疑点保留待核，不能把猜测当表值，也不能假报 PDF 页码。缺解析时请用户提供相关可读段落，并继续处理已有文字。缺 Word/PDF 导出不阻文本；导出和视觉核验交相应模块，不以文字检查冒充版式检查。

已确认 Python 3.11+ 可选用 scripts/environment.py --request text|docx|pdf|pages；这是 v04 原字节探测，不自动安装。PDF/页图探测需显式已有 runtime；不为文本任务运行 all。import/version 成功不代表文件解析/页面视觉通过。本包没有解析器、排版器、搜索引擎或统计引擎。

脚本命令和内部记录由宿主准备并校验，医生无需理解接口。没有脚本能力时逐项人工对照并标明该方式，严格计数/结构机器验收仍待核。
