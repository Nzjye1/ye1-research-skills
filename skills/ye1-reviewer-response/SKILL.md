# Ye1-审稿回复

直接读取审稿意见、原稿与现有修订稿/实际分析，保持意见编号并拆子点。每点给回复草稿、已做改动及当前版本位置；没有固定分页时用章节/段落，不编页行。合理未改给依据，计划补实验/统计标待做并交相应分析模块、获得必要研究确认。没有实际结果与稿件改动，不写“已经完成”。交逐点回复、改动对照和未完成清单；部分完成不称整封可提交，不实际投稿或代发。

先读 [共享事实与范围](references/common.md)。能力不明或附件/导出受限时再读 [环境分支](references/environment.md)。

本任务按需使用：[投稿与回复](references/publication.md)；[写作与一致性](references/writing.md)。

纯文本由当前宿主实际完成。可选 [文本工具](scripts/task_io.py) 做局部保存/数字token/计数/数字引文核对；需要机器辅助时读 [轻量接口](references/interface.md)，结果不等于语义验收。

首次加载、依赖缺失、升级或移除时见[独立使用与环境](references/portable-use.md)。
